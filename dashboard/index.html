How feedback works with two rear encoders

RL and RR are each compared with their own previous runs, so you can see whether a PWM change actually increased or reduced that wheel’s response. Because their tick scales are not yet proven equal, the console never ratio-matches RL against RR. Whole-robot heading and path feedback supplies the missing information and produces a small, reversible PWM trim using the mecanum wheel geometry.

BEST CURRENT METHOD

Guided floor PWM tuning

Adjust PWM inside the session, run a repeatable low-power move, describe heading and path error, then apply or reject a specific four-wheel trim.

WHEELS OFF THE FLOOR

Rear encoder response check

Verify direction, find a reliable motion threshold, and compare each rear encoder only with itself across PWM and power changes.

AFTER MOTOR BALANCE

Heading-hold tuning

Once open-loop PWM is repeatable, use fresh IMU yaw to tune heading correction. Motor tests keep heading correction disabled.

FUTURE HARDWARE

Four-encoder speed control

With normalized encoders on all wheels, the robot can build wheel-speed curves and close the loop without relying on visual feedback.
